# Day 1: PostgreSQL Introduction & Environment Setup

## What I Covered
- Learned what PostgreSQL is (an open-source Object-Relational Database Management System) and how SQL interacts with it.
- Installed PostgreSQL locally and noted down superuser credentials and default port (`5432`).
- Set up **pgAdmin 4** (GUI) and **psql** (CLI) to manage databases and run queries.

## Key Takeaway
- Every table is a database object, while other objects include views, indexes, sequences, functions, and triggers.
